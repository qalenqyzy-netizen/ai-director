# AI-Режиссёр

Помощник для AI-креаторов: уточняет бриф, строит драматургию и раскадровку и пишет промпты для генераторов изображений и видео. Паспорт героя и стиль повторяются в каждом промпте дословно, поэтому лицо, одежда и свет не «плывут» от кадра к кадру.

- `index.html` — приложение (одна страница, работает как артефакт Claude)
- `prd.md` — требования к продукту

Живая версия: https://claude.ai/artifact/BfhhFL3imSDrgLr6FGC7vW
